# 节日小屋 · AstrBot 插件

让 AI 住进一条有节日的街：出门撞见今天的景象，抬头看见今晚的月亮。
中秋（2026–2035 每年自动）前后，街上就是中秋的样子——不是播报「今天是中秋请开心」，是推开门自己撞见。

## 两个工具（AI 想用的时候自己调）

| 工具 | 干什么 |
|---|---|
| `chumen` | 出门走走。撞见今天街上的景象：普通日是晨午晚夜凌晨五段的市井；节日前后是节日的街（前夜饼店排队、正日天台拜月光、十六追月） |
| `yueliang` | 看今晚的月亮：多圆、什么时候升、是什么样子 |

街景抽卡是**洗牌制**：一套卡翻完一轮才重洗，出门四趟内每张必撞见一次。

## 安装

AstrBot 管理面板 → 插件管理 → 从仓库安装，填本仓库地址即可。

零依赖（纯 Python 标准库），无需额外安装任何包。

## 配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `city` | `佛山` | 家在哪个城市（影响月亮提示里的月出查询词） |
| `fake_date` | 空 | 试装开关：填 `2026-09-25` 可提前看中秋当天的街。**平时留空** |
| `fake_hour` | `-1` | 试装开关：0-23 假装现在几点，看不同时段街景。**平时 -1** |

## 街景内容

广府中秋：柚子灯、天台拜月光、紫苏炒田螺、剥鬼皮、追月。
普通日按时段：粥铺蒸气、凉茶铺葵扇、大排档镬气、凌晨磨米浆。

内容为「中秋礼盒」项目原创，另有零依赖 MCP 版（单文件 `festival_home.py`，任何支持 MCP 的客户端可用）。
